# SlideNext

<p align="center">
  <img src="logo.png" alt="SlideNext Logo" width="180" />
</p>

SlideNext is a modern presentation management and editing platform that lets users organize, edit, preview, and manage HTML-based presentations through a powerful visual studio.

## Features

- Presentation Library
- Visual Studio Editor
- Drag & Drop Editing
- Theme Management
- HTML Presentation Support
- Real-time Preview
- Multi-Presentation Management
- Responsive Dashboard

## Tech Stack

- HTML
- CSS
- JavaScript
- Express.js

## Development

```bash
npm install
npm start
```
