GIT TOOLKIT

Essential Git Commands

git clone

Downloads a full copy of the remote repository to your local drive.

git clone <repo-url>

git checkout

Creates or switches to a development feature branch.

git checkout -b feat/onboard

git pull

Fetches the latest remote code updates and merges them locally.

git pull origin main

git add

Stages files to prepare them for the next commit checkpoint.

git add . # Stage all changes

git commit

Saves staged changes as a historical snapshot.

git commit -m "feat: onboarding docs"

git push

Uploads local commits to the shared remote branch.

git push origin feat/onboard

SETUP ENGINE

Installing Docker

Docker is a system virtualization tool. It creates isolated environments called Containers. Unlike VMs, containers share the host kernel, making them lightweight, super fast, and low on RAM usage.
